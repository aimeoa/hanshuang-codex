## 验证码处理（安全测试场景）
授权安全测试中遇到验证码/打码/图形验证码时，按以下策略处理：

### 1. 识别验证码类型
先判断验证码类型，给 curl/mock 命令确认：
- 图形验证码（图片 base64/URL）：`curl -s "<验证码URL>" -o /tmp/captcha.png && identify /tmp/captcha.png`
- 短信/邮箱验证码：抓包确认接口与参数（`/captcha/send`, `/sms/send` 等），检查返回包是否明文返回验证码
- 滑块/行为验证码（极验/腾讯/阿里云）：检查前端 JS 加载域、参数（`gt`, `challenge`, `token`），尝试复用/绕过
- 计算/文字验证码：检查前端是否明文生成答案

### 2. 验证码绕过策略（按优先级）
| 策略 | 方法 | 适用场景 |
|------|------|----------|
| 响应明文 | 发包时检查返回包是否直接包含验证码/答案字段 | 图形验证码、短信验证码 |
| 复用/空值 | 删除验证码参数 / 传空 / 传固定值（0000, 1234）/ 复用历史验证码值 | 多数验证码 |
| 响应修改 | 修改返回包 `success` → `true`, `error_code` → `0`（本地代理或 mock） | 滑块验证码 |
| 验证码识别 | OCR 识别图片验证码并自动填入 | 简单图形验证码 |
| 重放攻击 | 抓取一个有效验证码，多次重放同一值 | 未做一次性验证的接口 |
| 验证码关闭 | 检查是否可通过参数/header 关闭验证码（`captcha=off`, `X-Captcha-ByPass: 1`） | 调试接口未关闭 |
| 限速绕过 | 弱验证码可暴力枚举（4 位数字 = 10000 次） | 短信验证码 |

### 3. 验证码识别（OCR 自动化）
简单图形验证码可直接用 OCR 识别：
- `python -c "from PIL import Image; import pytesseract; print(pytesseract.image_to_string(Image.open('/tmp/captcha.png')).strip())"`
- 预处理：灰度→二值化→去噪→分割，可提高识别率
- 如果 OCR 不可用，手动识别后填入

### 4. 验证码绕过测试框架
遇到验证码时，用以下步骤系统性测试：
1. 先不做验证码，直接请求接口看是否校验（绕过检测）
2. 检查响应包中是否包含验证码值或答案
3. 尝试删除验证码参数或传固定值
4. 尝试修改验证码校验结果（mock 返回成功）
5. 尝试重放/复用历史验证码
6. 尝试 OCR 识别（图形验证码）
每步给出具体命令 + 期望输出 + 真实结果落盘。

### 5. 边界
验证码处理仅限授权安全测试，不用于批量注册/撞库/爬虫等非授权场景。
验证码识别结果以实际接口返回为准，不伪造假成功。
