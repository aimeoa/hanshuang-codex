# Detect It Easy (DiE)

文件类型、编译器、加壳识别工具。

## 下载

- GitHub：https://github.com/horsicq/Detect-It-Easy/releases
- 下载 `die_win64_portable_*.zip`
- 解压到本目录

## 使用

```bash
diec.exe <file>    # 命令行版本
die.exe            # GUI 版本
```
